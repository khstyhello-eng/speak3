# speak3 — 3초 스피킹 연습 웹앱 설계

날짜: 2026-07-30
사용자: Khristy
상태: 설계 승인됨 (구현 전)

## 목적

영어 스크립트(미드 등)에서 뽑은 유용한 비즈니스/고난이도 문장을 "학습 → 큐를 보고 3초 안에 발화"로 훈련해 자기 문장으로 만드는 개인용 웹앱. 핵심 철학: **3초 안에 뱉을 수 있어야 내 문장이다.**

## 사용 환경

- 맥 크롬 + 안드로이드폰 크롬, 처음부터 두 기기 사용
- GitHub Pages로 호스팅 (정적 웹앱, 서버 없음)
- 음성인식·TTS는 브라우저 내장 Web Speech API 사용

## 콘텐츠 범위

- 1차: 미드 섹션 — Suits S1E1(Pilot), S1E2(Errors and Omissions)
- 원자료: `raw/` 폴더의 스크립트 3종 (자막 스타일 2편 + 1화 화자 표기판)
- 추후 확장: 연설문, TED, 고급 행사 진행 멘트 등 섹션 추가
- 문장 선정: Claude가 비즈니스/고난이도 유용문장 큐레이션(한국어 뜻·해설 포함, 에피소드당 40~60개 목표) + 문장 브라우저에서 사용자가 직접 추가

## 화면 구성 (4개)

1. **홈**: 오늘 만기 복습 개수, 섹션별 진도(내 문장 수), 시작 버튼
2. **학습 모드**: 새 문장 첫 학습 — 영어 원문, 한국어 뜻, 표현 해설(비즈니스 뉘앙스), 드라마 속 앞뒤 대사 맥락, TTS 듣기, 따라 읽기 → "발화 연습으로" 버튼
3. **발화 모드 (핵심)**: 큐 표시 + 3초 타이머 + 마이크 자동 시작 → 음성인식 결과를 정답과 대조 → 판정 → SRS 갱신
4. **문장 브라우저**: 에피소드 전체 스크립트 열람, 큐레이션 문장 표시, "+"로 연습 목록 추가

## 핵심 학습 루프

### 3초 룰의 정의

- 큐가 뜬 뒤 **3초 안에 발화를 시작**하면 통과 후보 (문장 완성 시간은 제한 없음)
- 말한 내용이 정답과 충분히 일치해야 성공: 핵심 단어 기준 약 80% 일치, 사소한 축약·관사 차이 허용

### 판정 3단계

| 판정 | 조건 | SRS 효과 |
|---|---|---|
| 실패 | 3초 초과 시작, 발화 없음, 불일치 | 간격 1일로 리셋 |
| 겨우 성공 | 성공했지만 더듬거림 (본인 선택) | 간격 유지 (같은 간격 반복) |
| 즉답 성공 | 3초 내 시작 + 일치 | 간격 정상 성장 |

성공 판정 시 기본값은 "즉답 성공"이며, 결과 화면의 "겨우 했어요" 버튼으로 스스로 한 단계 낮출 수 있다. "약 80% 일치"의 정확한 기준(소문자화·구두점 제거·축약 통일 후 내용어 매칭)은 구현 시 테스트로 고정한다.

### 큐 단계 (문장별 자동 승급)

- 1단계: 한국어 뜻 → 2단계: 상황 설명 또는 상대방 대사
- 승급 조건: 해당 문장의 SRS 간격이 7일에 도달하면 2단계 큐로 전환

## 데이터 구조

### 콘텐츠 (정적 JSON, 저장소에 커밋)

```
data/
  sections.json            # 섹션 목록 (미드/연설문/TED/행사멘트…)
  drama-suits-s01e01.json  # 소스 1개 = 파일 1개
  drama-suits-s01e02.json
```

문장 필드: id, 영어 원문, 한국어 뜻, 표현 해설, 앞뒤 대사(맥락), 상황 큐 문구, 화자, 태그(협상/설득/반박 등), 큐레이션 여부.

새 소스 추가 = 같은 형식의 JSON 파일 추가 → 앱이 자동 인식.

### 학습 기록 (콘텐츠와 분리)

- 문장 ID별: 다음 복습일, 현재 간격, 큐 단계, 성공 이력, 최종 수정 시각
- 콘텐츠 파일을 갱신해도 학습 기록이 깨지지 않는 구조

## SRS 알고리즘 (SM-2 단순화)

- 간격 성장: 1일 → 3일 → 7일 → 16일 → … (×2.2)
- 즉답 성공 = 성장, 겨우 성공 = 유지, 실패 = 1일 리셋
- 홈에는 오늘 만기 문장만 표시
- 신규 문장 학습은 하루 5개 제한 (설정에서 변경 가능)

## 동기화 (맥 ↔ 안드로이드폰)

- 학습 기록은 localStorage에 우선 저장 → 변경 시 비공개 GitHub Gist로 자동 업로드
- 앱 시작 시 Gist에서 받아와 병합, 충돌은 문장별 **최신 타임스탬프 승리**
- 최초 1회 GitHub 토큰을 설정 화면에 입력 (기기당 1번)
- 오프라인/Gist 실패 시에도 학습은 정상 진행, 다음 연결 때 업로드

## 에러 처리

- 마이크 권한 거부 또는 음성인식 3회 연속 실패 → 해당 문장 자기평가 모드(⭕/❌)로 자동 전환
- 오인식 시 "내가 맞았음" 수동 정정 버튼
- TTS 음성 미지원 등 기기 차이는 해당 기능만 숨기고 나머지 동작

## 검증 계획

- 자동 테스트: SRS 스케줄 계산, 발화 텍스트 대조(정규화·매칭) 로직
- 실기기 확인: 맥 크롬에서 실행 시연, 안드로이드폰은 체크리스트로 사용자 확인

## 범위에서 제외 (YAGNI)

- 로그인/백엔드 DB, 타인 서비스용 기능
- 녹음 재생·발음 비교, 역할극 모드, 통계 대시보드(간단한 카운트 이상)
- iOS 지원 (필요해지면 자기평가 폴백으로 대응)
