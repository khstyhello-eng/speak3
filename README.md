# speak3 — 3초 스피킹

미드 스크립트의 비즈니스 문장과 연설문의 격식 표현을 "한국어 큐 → 3초 안에 영어로 발화"로 훈련하는 개인용 웹앱.
3초 안에 뱉을 수 있어야 내 문장이다.

## 사용법

- 배포 주소: https://khstyhello-eng.github.io/speak3/
- 로컬 실행: `python3 -m http.server 8000` → http://localhost:8000 (마이크 권한 때문에 file:// 로는 열지 말 것)
- 테스트: `npm test`

## 흐름

1. **학습** 탭에서 새 문장(하루 5개 기본)을 학습 → 오늘 발화 목록에 추가
2. **발화** 탭에서 큐를 보고 3초 안에 말하기 → 음성인식 자동 판정
3. SRS(1→3→7→15일, 이후 ×2.2)가 다음 복습일을 결정. 간격 7일 도달 시 큐가 상황/상대대사로 승급
4. **문장** 탭에서 전체 스크립트를 보며 원하는 문장 직접 추가

## 맥↔폰 동기화 설정 (최초 1회)

1. GitHub → Settings → Developer settings → Personal access tokens (classic) → Generate new token
2. 권한은 **gist만** 체크, 만료는 원하는 대로
3. 앱 설정 탭에 토큰 붙여넣기 → "연결" (첫 기기는 Gist 새로 생성, 두 번째 기기는 자동으로 같은 Gist를 찾음)

## 안드로이드폰 확인 체크리스트

- [ ] 크롬에서 배포 주소 열기 → 홈 화면 표시
- [ ] 발화 탭 → 마이크 권한 허용 → 카운트다운·인식·판정 동작
- [ ] 설정 탭 → 같은 토큰으로 연결 → 맥에서 공부한 진도가 보이는지
- [ ] 폰에서 1문장 발화 후 맥에서 새로고침 → 진도 반영 확인

## 확인 체크리스트 (배포 후)

- [ ] 크롬에서 배포 주소 열기 → 홈 화면 표시
- [ ] 발화 탭 → 마이크 권한 허용 → 카운트다운·인식·판정 동작
- [ ] 설정 탭 → 같은 토큰으로 연결 → 맥에서 공부한 진도가 보이는지
- [ ] 폰에서 1문장 발화 후 맥에서 새로고침 → 진도 반영 확인
- [ ] 홈: 발화 카운트·새 문장 남은 개수 표시, 발화 0개면 버튼 비활성
- [ ] 학습→발화: 새 문장 5개 학습 후 발화 목록에 등장
- [ ] 발화: 첫 실행 시 마이크 권한 프롬프트 때문에 1번 문항이 시간 초과로 뜰 수 있음 — "내가 맞았음"으로 정정 (알려진 제약)
- [ ] 문장 브라우저: "Okay." 같은 반복 대사 하나를 추가해도 다른 위치의 같은 대사에는 + 버튼이 남아 있는지
- [ ] 문장 브라우저: 소스 A/B를 빠르게 전환해도 마지막 클릭한 소스가 표시되는지
- [ ] 설정: 하루 새 문장 개수에 100 입력 → 50으로 클램프되는지
- [ ] 설정: 하루 새 문장 개수에 0 입력 → 1로 클램프되는지
- [ ] 설정: 내보내기 JSON에 token/gistId가 없는지
- [ ] 동기화: 맥에서 학습 → 폰 새로고침 → 진도 반영 (역방향도)
